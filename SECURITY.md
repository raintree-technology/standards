# Security policy

This repository contains documentation, schemas, and validation scripts. Security reports may concern unsafe guidance, exposed sensitive information, malicious content, or a vulnerability in repository automation.

## Report a vulnerability

Do not open a public issue for a concern that contains sensitive information or could put users at risk.

Email [hello@raintree.technology](mailto:hello@raintree.technology) with the subject `Standards security report`. Include the affected file or workflow, the risk, reproduction details when applicable, and a safe way to confirm the issue.

You may also use the repository's **Security** tab when private vulnerability reporting is available.

Use a public GitHub issue for non-sensitive corrections and documentation problems.

## Response

Maintainers will assess the report, limit further exposure when necessary, and record any correction or exception supported by the available evidence. No response time is guaranteed while this project remains under active development.
