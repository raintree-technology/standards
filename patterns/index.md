# Patterns

* [Federated organizational knowledge](federated-knowledge.md) - Keep native sources authoritative while adapters produce governed evidence for shared retrieval.
* [Cross-layer policy conformance](cross-layer-policy-conformance.md) - Preserve canonical policy obligations across exposed capabilities, validation, execution, containment, and release.
* [Verified agent workflow](verified-agent-workflow.md) - Separate variable model work from independent validation, bounded execution, and release decisions.
